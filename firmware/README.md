# M1 demonstration firmware

The testbench assembles and loads two programs through the top-level Host bus. The square-wave program is `OE(1), SET(1), WAIT(2), SET(0), WAIT(2), JMP(1)`. The reactive program is `OE(1), WAIT_PIN(1,1), SET(1), WAIT(2), SET(0), JMP(1)`. Their 16-bit words are generated by `tools/assembler/isa.py`, never hardwired into the RTL.

These programs demonstrate the loader and exact-cycle checking. They do not implement UART, SPI, or I²C.
